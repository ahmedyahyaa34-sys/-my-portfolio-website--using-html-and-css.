# Portfolio and Contact Website

A simple two-page personal website built with HTML and CSS. It introduces who I am, shows my work, and gives visitors a way to contact me.

**Live site:** https://your-username.github.io/your-repo

## Pages

### 1. Portfolio (`index.html`)
- About me
- Skills
- Projects, with links to each one
- Navigation link to the contact page

### 2. Contact (`contact.html`)
- Contact form with name, email, and message fields
- Email address and social links
- Navigation link back to the portfolio

## Built With
- HTML5: page structure, links, lists, and forms
- CSS3: layout, box model, borders, and colours
- GitHub Pages: free hosting

## Project Structure
```
your-repo/
├── index.html      # Portfolio page
├── contact.html    # Contact page
└── README.md
```

## Run It Locally
1. Clone the repository:
   `git clone https://github.com/your-username/your-repo.git`
2. Open `index.html` in your browser.
